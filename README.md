## 🎯 個案核心現況與背景
- **個案代號**：怡君子（怡君之子）
- **年齡**：6 歲（學齡前 / 大班升國小一年級）
- **生長體格**：身高體重標準（成長發育符合標準曲線）
- **常規用藥**：**辛特昂錠 (Syntroxine / 左旋甲狀腺素)**（治療甲狀腺功能低下）
- **衍生困擾**：**造成便秘**（甲狀腺低下生理蠕動慢 ＋ 精緻無纖維飲食）

- **飲食特徵**：偏愛「白色食物」（起司、白飯、白麵）
- **三餐現況**：

## 💊 紐崔萊關鍵營養素配置階梯
1. **第一步（腸道修復與菌相）**：紐崔萊 益生菌
2. **排便軟化與神經放鬆**：加美D鈣錠（純淨海藻鈣 ＋ 鎂 ＋ D3，**【鎂元素助通便】**，安排於晚餐後）
3. **神經髓鞘與抗發炎潤腸**：純淨深海魚油 (Omega-3 DHA/EPA)
4. **專注傳導物質合成**：紐崔萊 卵磷脂粉 / 嚼片（膽鹼 ＋ 乳化潤腸）
5. **細胞基底能量穩定**：全植物優質蛋白素（PDCAAS=1，放學或晚餐補充）
