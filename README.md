## 🔬 營養學與健管諮詢三大核心切入點

### 1. 腸腦軸線 (Gut-Brain Axis) 與外啡肽
起司中的**酪蛋白 (Casein)** 與麵食中的**麩質 (Gluten)** 在腸道屏障未健全（腸漏）時，未完全分解的胜肽會形成**外啡肽 (Casomorphin / Gluteomorphin)**，穿透血腦屏障刺激類鴉片受體，干擾大腦專注力、加劇感官敏感與固定行為。

### 2. 精緻澱粉與血糖震盪
白飯與白麵屬於高升糖指數 (GI) 精緻碳水化合物，消化吸收過快使血糖急升驟降，容易誘發神經亢奮後急速分心疲憊。

### 3. 漸進混搭換色法（不強硬剝奪）
自閉特質孩童多有感覺敏感或固著行為，強硬切除白色食物易引起對立與抗拒。應採取：
- 白飯中混入 10% 彩米、地瓜丁或花椰菜碎米。
- 晚餐以「彩虹餐盤 ＋ 好油脂（深海魚鮭魚/鯖魚）」為核心。
- 早餐水煮蛋搭配全植物蛋白素與卵磷脂粉溫飲，平穩大腦能量釋放。
